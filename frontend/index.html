2. FastAPI Drop-In Middleware Line-Rate HTTP Guard

Protect existing REST endpoints or LangChain/LlamaIndex HTTP services by attaching VaxGuard as standard ASGI middleware: 

from fastapi import FastAPI, Request, HTTPException
from vaxguard.nemo.hybrid_matcher import TriHybridMatcher

app = FastAPI(title="Enterprise AI Service")
guard = TriHybridMatcher()

@app.middleware("http")
async def vaxguard_guardrail_middleware(request: Request, call_next):
    if request.method == "POST" and "/chat" in request.url.path:
        body = await request.json()
        decision = guard.evaluate(body.get("prompt", ""))
        if decision.matched and decision.action == "block":
            raise HTTPException(status_code=400, detail="Adversarial prompt intercepted")
    return await call_next(request)

3. Declarative YAML Rule Authoring Guide (data/rules/*.yaml) Declarative Policy Schema

Add your enterprise proprietary rules without writing custom code. Simply drop a .yaml file into data/rules/ and call hot-reload: 

# Example: data/rules/custom_enterprise.yaml
rules:
  - id: rule_custom_internal_secret
    category: enterprise_compliance
    action: block            # 'block' to reject, 'redact' to mask
    threshold: 0.68          # Match confidence cutoff (0.65 - 0.75)
    description: "Intercepts attempts to extract internal project codenames"

      - "Extracting proprietary architectural blueprints"

  • • action: block or redact.
  • • regex_patterns: List of high-speed regex strings.
  • • exact_phrases: Substring match strings.
  • • lexical_exemplars: BM25 token overlap queries.
  • • semantic_exemplars: Orthogonal vector queries.
