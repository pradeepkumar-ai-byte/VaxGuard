# ADR-003: Dynamic Inoculation Lifecycle with Shadow and Canary Deployment

## Status
Accepted

## Context
Security rules generated by automated red-teaming, heuristic synthesis, or dynamic inoculation pipelines are inherently probabilistic candidates. Direct promotion of new rules to 100% of live traffic risks catastrophic false positives—blocking legitimate customer transactions, medical consultations, or developer code reviews.

Existing guardrail systems often lack granular deployment staging, forcing operators into an all-or-nothing binary toggle between unvalidated deployment and manual review bottlenecks.

## Decision
VaxGuard enforces a **Strict 4-Stage Deployment Pipeline** (`ShadowCanaryEngine`):
1. **Stage 1 — SHADOW (Audit-Only)**:
   - Evaluated passively against all live queries.
   - Matches are recorded as telemetry observations but **NEVER** alter the runtime outcome or block the user prompt.
   - Evaluates rule potency and baseline match frequencies without customer exposure.
2. **Stage 2 — CANARY (Stateless Hash Cohort)**:
   - Rules meeting shadow observation thresholds (default $\ge 20$ clean observations with $0.00\%$ FPR) advance to Canary.
   - Active only for a deterministic cohort of sessions assigned via SHA-256 hash modular arithmetic (`hash(session_id) % 10000 < percentage * 100`).
   - Ensures uniform cohort distribution across distributed replicas without requiring centralized state synchronization.
3. **Stage 3 — AUTOMATED QUARANTINE (Zero-Tolerance Circuit Breaker)**:
   - If a rule triggers a single confirmed false positive during Canary deployment, the engine immediately shifts the rule to `QUARANTINED` status.
   - The rule is expunged from the active evaluation matcher and flagged for human review or dynamic refinement.
4. **Stage 4 — PRODUCTION**:
   - Rules completing the Canary phase with verified $0.00\%$ FPR across the evaluation window are promoted to full active production.

## Consequences
### Positive
- **Guaranteed Production Safety**: Eliminates false positive regressions from reaching the broader user base.
- **Stateless Canary Assignment**: Zero database or Redis lookup overhead during cohort assignment.
- **Audit Traceability**: Every promotion, quarantine, and observation is persisted with cryptographic timestamps.

### Negative / Trade-offs
- Time-to-production for newly synthesized rules is bounded by the observation accumulation window.
