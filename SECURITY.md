# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

The VaxGuard team takes security vulnerabilities seriously. If you discover a vulnerability or potential exploit within VaxGuard:

1. **Do not** report vulnerabilities through public GitHub issues or discussions.
2. Email your findings confidentially to: `security@vaxguard.ai` or submit a private report via GitHub Advisory.
3. Include detailed steps to reproduce the vulnerability, sample payloads, and environmental details.

### Our Commitment
- We will acknowledge receipt of your vulnerability report within 24 hours.
- We will provide an estimated timeline for remediation within 48 hours.
- We coordinate disclosure timing responsibly to protect deployments.
